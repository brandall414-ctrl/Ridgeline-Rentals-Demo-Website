# Trailside site — how it's built (updated Nov 14, 2026)

Pages: `index.html` (home), `info.html` (everything you need to know), `rates.html`, `agreement.html`, `book.html`.
Styles: `css/apple.css` (Apple system + booking), `css/home.css` (home + shared nav/footer + inner pages), `css/info.css`.
Scripts: `js/config.js` (all prices and rules), `js/home.js`, `js/inner.js`, `js/info.js`, `js/booking.js`, `js/agreement.js`.
Rates, agreement and info are generated by `build_inner.py` (scratchpad) from one template so nav and footer match the homepage.

## Rules Ben set (Nov 14)
- No pinned or scroll-locked sections anywhere. Light parallax only.
- Keep the two-carabiner rail on the left of the homepage.
- Mobile gets its own layouts (collage positions use --mx/--my/--mw; gear and prices compress), not just smaller desktop.

## Homepage order
Cover ("Gear up at the trailhead.", climber cutout) → photo collage with the ladder video (3D layered tiles, fly in once,
tilt to the pointer, small depth parallax) → Right in the parking lot (map) → Kit (3 static cards, prices, duo deal)
→ How it works (sticky phone with real booking screenshots from `assets/screens/`; inline screenshots on phones)
→ Before you go (3 tips + link to info.html) → More from the gorge (native swipe row) → See you at the trailhead.

## Pricing (js/config.js)
1 or 2 days = base price. Days 3–4 add extraDay per item (kit $10, lanyard $8, helmet/harness $5). Max 4 days online.
Duo deal: $10 off each pair of kits/lanyards (any mix), up to 2 pairs. Gear Protection is the default and includes free
cancellation until day one; card hold = free cancellation up to 7 days before, then date changes only.
Return by 11:59 pm on the last day. Lockers 24/7.

## Refresh the phone screenshots
Run `screens.py` (scratchpad) against the local server after any booking UI change.
